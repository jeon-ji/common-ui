Table 추가 — 표시만 담당하는 표. 정렬·필터·페이징 **로직은 전부 소비 앱이 소유한다**.
`columns`의 `render`가 필수라 컬럼 key가 데이터 필드에 묶이지 않고, 정렬은 `sort`/`onSortChange`
제어형이라 서버 정렬로 갈아 끼울 수 있다. 빈 상태는 슬롯(`empty`)이어서 Table이 EmptyState를
import 하지 않는다. 고정 헤더·고정 컬럼을 지원하며 고정 컬럼의 그림자는 셀 종류마다 복사하지 않고
`data-sticky` 셀렉터 두 개가 그린다. 스크롤될 여지는 prop이 아니라 CSS 변수로 소비자가 정한다 —
고정 헤더에는 `--ui-table-max-height`, 고정 컬럼에는 `--ui-table-min-width`가 필요하다. **`role="grid"` 키보드 내비게이션은 하지 않는다** — 정적
데이터 표시가 이 컴포넌트의 범위이고, 행 안의 버튼·체크박스·링크는 각자 네이티브 탭 스톱이다.
가상화·페이징 내장·컬럼 재정렬·확장 행·셀 편집·다단 헤더도 범위 밖이다.
